# 新Index公開統合

このブランチは、新Index・ランキング/NEWS・ポイントサイト紹介ページと、一般記事2本（ポイントサイトの選び方 / ゲーム案件の選び方）を統合した公開候補です。

検証済み:
- build.py
- ranking parser / snapshot checks
- NEWS parser checks
- daily recommendation checks
- collector fallback checks
- 全リンク・アンカー・紹介URL・画像属性・SVG・再現ビルド
- docs/dist 同期
- 新着記事と今週の特集への2記事反映

自動公開方式はWork復帰後に完成予定。公開後それまではランキング/NEWSを手動更新します。
