# Visual assets

The SVG process thumbnails in dist/visuals are original POI DAYS informational diagrams, generated by scripts/visuals.py. They use only abstract nodes, arrows and descriptive text. No third-party images, logos, product artwork or screenshots are reproduced. They are not representations of official registration screens.

Offer thumbnails summarize the already dated conditions; they do not refresh the offer record or guarantee approval. All diagrams have alternative text and explicit dimensions. The four-step flow uses real HTML text and stacks vertically on narrow screens. Existing hero image, colors, cards and referral destinations remain unchanged.

Validation: all twelve pages, local image references, alt text, SVG XML syntax, generation repeatability, referral links and JS syntax. Browser rendering remains untested because static Sites have no supported agent-preview server in this environment. No claim of completed iPhone visual QA.
